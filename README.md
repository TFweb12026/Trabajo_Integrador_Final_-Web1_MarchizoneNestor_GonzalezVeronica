NodeStack – Soluciones en Bases de Datos
Descripción del Proyecto: NodeStack es un sitio web desarrollado como trabajo integrador de la materia Programación Web 1. El proyecto tiene como objetivo presentar un servicio de soluciones relacionadas con bases de datos, mostrando información sobre los servicios ofrecidos y ofreciendo un medio de contacto para los interesados.
El sitio fue desarrollado utilizando HTML, CSS y JavaScript.
Tecnologías Utilizadas: 
-HTML: Estructura y contenido de las páginas.
-CSS: Diseño visual, estilos y distribución de los elementos mediante Flexbox.
-JavaScript: Funcionamiento del carrusel de imágenes, manejo de eventos y validación del formulario.
-Google Fonts: Tipografías Space Grotesk y JetBrains Mono.
Estructura del Proyecto:
- index.html
- servicios.html
- contacto.html
- styles.css
- script.js
- imagenes- imágenes utilizadas en el sitio
Páginas del Sitio
Inicio: Presenta NodeStack, una descripción general de la propuesta y un carrusel de imágenes con controles para avanzar y retroceder.
Servicios:Muestra los principales servicios relacionados con bases de datos y soluciones informáticas.
Contacto: Contiene un formulario para que los visitantes puedan enviar sus datos y realizar consultas.
Características Implementadas:
-Sitio web compuesto por tres páginas HTML.
-Menú de navegación compartido.
-Identificación visual de la página activa.
-Diseño adaptable a distintos tamaños de pantalla.
-Uso de Flexbox para organizar los elementos.
-Carrusel de imágenes con botones de navegación.
-Validación de campos del formulario mediante JavaScript.
-Manipulación de elementos HTML mediante el DOM.
Diseño:Se utilizó una paleta de colores oscuros con detalles en tonos dorados y verdes. También se incorporaron tipografías de Google Fonts para mantener una identidad visual uniforme en las distintas páginas.
Cómo Ejecutar el Proyecto:
-Descargar o clonar el repositorio.
-Abrir la carpeta del proyecto.
-Ejecutar el archivo index.html desde un navegador web.
-Navegar por las distintas secciones utilizando el menú principal.
